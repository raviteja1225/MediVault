# MediVault

MediVault is a secure medical record storage and sharing platform developed as a college project.

#frontend link
https://medi-vault-2z7x.vercel.app


## Tech Stack

- **Frontend:** React + Vite + Bootstrap
- **Backend:** Python + Django REST Framework (DRF)
- **Database:** SQLite

## Project Overview

MediVault aims to provide a centralized and secure system for users to store, manage, and share their medical history, prescriptions, and diagnostic reports safely.
